# Changelog

## v2.0.0 — Acoustic Studio / Vinyl Room

- Make the approved photographic walnut headstock and warm vinyl room the
  default GitHub Pages experience.
- Enlarge and center the instrument; make note labels and brass pegs tappable.
- Keep clear cents feedback above the instrument and tuck 20 presets into a
  desktop side list / phone sheet. Sound and mic controls open separately.
- Use familiar note letters without octave digits.
- Keep the blue view at `?v=1`, with a permanent v1.0.0 release checkpoint.
- Curate the deployed artifact, remove superseded samples and browser tooling,
  scope offline caches to this app and gate Pages deployment on tests.

## v1.0.0 — Blue tuner

- Preserve the completed blue interface and 20 common standard, lowered, drop,
  open and modal guitar presets.
- Bundle Pitchy/McLeod analysis with noise, clipping and signal checks.
- Improve microphone selection, capture cleanup, stable cents and string locking.
- Add 41 calibrated recordings across steel-string, nylon and electric voices,
  plus pure-tone playback.
- Include offline assets, credits and 12 automated software checks.
